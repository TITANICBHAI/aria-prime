Architecture

Built from the ground up — no wrappers

Every layer is hand-built. The agent loop drives a read-decide-act-observe cycle with real OS integration — not a chatbot dressed up as an agent.

1,063-Line AgentLoop

The core orchestration engine drives a continuous read → decide → act → observe cycle. Circuit breakers, event routing, and health monitors keep every component accountable.

llama.cpp via JNI

Custom C++ JNI bridge to llama.cpp for quantized GGUF model inference directly on the Android GPU — OpenCL acceleration, native crash handling, and direct memory management.

SAM2 Vision Engine

A SAM2 visual segmentation engine gives the agent spatial awareness of the screen — understanding UI regions without relying on view hierarchy alone.

AccessibilityService Context

Android AccessibilityService provides deep screen-reading context — the agent understands what is visible and interactive without root or special permissions.

Gesture Execution Engine

Drives real Android gestures — taps, swipes, scrolls — using AccessibilityService gesture injection. The agent physically interacts with apps, not just reads them.

RL Policy Network

A reinforcement learning policy network shapes agent decision-making over time — improving action selection based on observed outcomes across sessions.
