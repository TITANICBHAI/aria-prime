Architecture

Built from the ground up.
No wrappers. No shortcuts.

Every layer is purpose-built. The agent loop drives a real read-decide-act-observe cycle with live OS integration — not a chatbot with a fancy UI on top.

01

AgentLoop — 1,063 lines

The central orchestration engine drives a continuous read → decide → act → observe cycle. Circuit breakers prevent runaway actions, an event router dispatches signals between subsystems, and a health monitor tracks the state of every component in real time.

02

llama.cpp via JNI / NDK

A custom C++ JNI bridge calls llama.cpp directly from the JVM, running quantized GGUF models on the device GPU via OpenCL. The native layer handles memory allocation, model context, token sampling, and crash recovery — bypassing the JVM for all math-critical paths.

03

SAM2 Visual Segmentation Engine

A SAM2 model gives the agent spatial awareness of the screen — identifying UI regions, boundaries, and interactive zones by visual segmentation rather than relying solely on the accessibility view hierarchy.

04

AccessibilityService Screen Context

Android's AccessibilityService provides deep real-time screen context — the agent sees what is visible, what is focusable, and what text is on screen, without root or special system permissions.

05

Gesture Execution Engine

The agent executes real Android gestures — taps, swipes, long-presses, scrolls — via AccessibilityService gesture injection. It physically interacts with apps at the OS level, not through simulated events.

06

Reinforcement Learning Policy Network

A policy network shapes agent decision-making across sessions — improving action selection quality over time based on observed outcomes, building a local behavioral model that adapts to how you use your device.
